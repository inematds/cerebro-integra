# fontes/

Material bruto, do jeito que chegou: transcrições de reunião e de vídeo, exportações, documentos, artigos, anotações soltas.

Regras:

- **Não edite** o que está aqui. É a matéria-prima. A interpretação vai para `wiki/`.
- Nomeie com data e assunto: `2026-09-07-reuniao-cliente-x.md`.
- Subpastas por tipo ajudam quando o volume cresce: `reunioes/`, `videos/`, `documentos/`.
- Rode `/wiki` para transformar o que chegou em páginas interligadas.

O `/wiki` mantém em `wiki/log.md` o registro do que já foi processado, então pode acumular material aqui sem medo.
