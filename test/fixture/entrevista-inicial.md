# Entrevista inicial

Este é o arquivo-fonte do seu cérebro. Preencha digitando, ditando, ou rodando `/iniciar` para uma conversa guiada. De qualquer forma, é este arquivo que o `/iniciar` lê para montar a estrutura do dia 1.

**Limite: 7 perguntas.** Cada uma se responde em menos de um minuto. Não pense demais: você pode editar e rodar `/iniciar` de novo quando quiser.
