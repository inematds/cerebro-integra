# referencias/

Material de referência que o agente consulta para fazer o trabalho do seu jeito.

- `voz.md`: amostras da sua escrita, coladas sem edição. Criado por `/iniciar`.
- `<ferramenta>-api.md`: um guia por ferramenta conectada (endpoints, autenticação, consultas comuns). Criado quando você conecta algo.
- `procedimentos/`: passo a passo de processos recorrentes, quando existirem.

Não é depósito de material bruto. Bruto vai em `fontes/`.
