# projetos/

Um subdiretório por projeto ativo. Cada um começa com um `README.md` que responde:

- O que é e por que existe.
- Estado atual e próximo passo.
- Onde estão os entregáveis.
- Decisões relevantes (link para `decisoes/registro.md`).

Ao criar um projeto, rode `/vincular projetos/<nome> "quando usar"` para que o manual saiba que ele existe. Projeto encerrado vai para `arquivo/`.
