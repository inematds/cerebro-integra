# wiki/

Páginas de conhecimento interligadas, escritas e mantidas pelo agente a partir de `fontes/`. É aqui que as relações aparecem: pessoa ↔ projeto ↔ decisão ↔ reunião.

Estrutura mantida pelo `/wiki`:

- `index.md`: catálogo de todas as páginas, com uma linha por página. Sempre leia primeiro.
- `log.md`: registro cronológico do que foi ingerido, criado e revisado.
- `entidades/`: pessoas, empresas, produtos, ferramentas.
- `conceitos/`: temas, métodos, ideias recorrentes.
- `fontes/`: uma página-resumo por fonte bruta processada, com link para o original.

Convenções:

- Links entre páginas com `[[nome-da-pagina]]`.
- Cabeçalho de cada página com `atualizado: AAAA-MM-DD` e `fontes:` listando as origens.
- Fato que muda (número, prazo) leva data ao lado. Fato estável não.
- Conflito entre fontes é anotado na página, não resolvido em silêncio.

Nunca edite `fontes/`. Edite a wiki.
