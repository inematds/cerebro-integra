# contexto/

Contexto estável sobre você. O que muda pouco: quem você é, o que faz, para quem, o que importa neste trimestre.

Preenchido por `/iniciar`:

- `sobre-mim.md`: identidade, função, a tarefa que come sua semana.
- `sobre-o-trabalho.md`: oferta ou função, público, modelo de receita (se houver).
- `prioridades.md`: as 2 ou 3 prioridades dos próximos 90 dias, uma por linha. Fonte canônica.

Ampliado por `/entrevista`: fatos confirmados em entrevistas entram aqui com link para a captura de origem.

Dado que muda todo dia (agenda, tarefas, métricas) não mora aqui. Vem das conexões.
